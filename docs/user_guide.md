# 用户指南

## 首次启动

双击 `BinaryAlchemist.exe`（或 `python main.py`）。左侧导航按分类列出全部
工具；仪表盘显示最近任务与最近报告。所有分析均为本地执行，不会上传数据。

## 使用工具

1. 在左侧选择分类与工具。
2. 填写参数（文件参数可拖拽文件到页面，只取路径、不会执行样本）。
3. 点“开始/检测”，任务进入后台；可随时“取消”。
4. 结果在下方面板展示（统计卡片 / 表格 / Finding 视图），日志在日志区。
5. 结果可复制、导出 JSON/TXT/CSV，也可通过“发送到”传给其他工具。

长任务（TCP 扫描、MD5 字典/暴力、文件批量分析、CTF 流水线）都有进度与
速度统计，取消后不会继续产生新工作。

## 任务历史

每个任务都会自动记录到 SQLite。历史页支持搜索（任务 ID/工具/摘要/插件）、
按工具/分类/状态/时间筛选、50 条分页、查看结果、重新执行与导出。被报告
引用的任务不能直接删除，需先从报告中移除。

## 报告中心

新建报告后选择模板（基础/Web/文件/系统/CTF），添加任务引用、编写各节说明
与结论，导出 Markdown/JSON/TXT。Finding 按严重度排序展示，不构成漏洞
判定；报告结尾附带静态分析免责声明。

## 插件

插件页列出发现的插件，可启用/禁用/刷新；状态跨重启保存。插件与主程序同
进程运行，请只安装可信插件。

## CTF 工作台

为每个挑战建立本地工作区（附件/笔记/结果/流水线）。附件永不执行；流水线
默认只允许本地工具，拒绝主动网络工具。

## 数据维护

“设置 → 数据维护”可查看孤立结果文件与断链报告引用的数量，并可主动清理。
默认只报告问题，不会自动删除任何数据。

## 安全边界

本工具集用于安全学习、CTF、实验环境与授权测试。网络模块仅做 TCP 连通性
检测；文件模块为纯静态分析；系统模块默认只读。请勿对未授权的目标使用。
