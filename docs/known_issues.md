# 已知问题（阶段 12 交付时）

以下问题为当前已知的低风险遗留项，均不影响阶段 12 的质量门槛判定。

## 功能层面

1. **报告编辑为手动保存**：报告中心没有自动保存；关闭前需手动点“保存”。
2. **Markdown 预览为纯文本**：`QTextBrowser` 以纯文本展示，未做富 Markdown
   渲染。
3. **历史页缺少自定义日期范围**：支持时间筛选的预设区间，不支持任意起止
   日期。
4. **HTML / PDF 报告导出**：仅有预留接口（`HTMLReportExporter` /
   `PDFReportExporter`），尚未实现。

## 打包与运行环境

5. **窗口化 EXE 的 `--version` 无可见输出**：`console=False` 的 GUI 程序没有
   控制台，命令行输出不可见；版本号仍显示在 GUI 状态栏且来源统一。
6. **便携模式为显式选择**：冻结应用默认把用户数据写入
   `%LOCALAPPDATA%\BinaryAlchemist`；如需“随身 U 盘”式便携布局，需在 EXE
   旁放置 `portable.flag`（或设置 `CYBERTOOLKIT_HOME`）。程序不写注册表。
7. **构建工具依赖虚拟环境解释器**：`python scripts/lint.py` 等脚本使用
   当前解释器；若系统 `python` 不是项目虚拟环境，需改用
   `.venv\Scripts\python.exe` 运行。

## 安全边界说明

8. **正则复杂度防护为启发式阈值**：超过 4KB 且命中高复杂度模式时拒绝执行；
   阈值之内的病态表达式仍可能在后台工作线程耗时（GUI 不受阻塞），可取消但
   无法强制中断正在执行的 C 级正则匹配。
9. **插件同进程运行**：插件与主程序同进程、同权限，无沙箱；只能安装可信
   插件。此为本项目的明确设计边界，非缺陷。
10. **Qt 的 ICU 依赖来自操作系统**：PySide6 轮子不附带 `icuuc.dll`，运行时
    使用 Windows 自带的 ICU（Windows 11 已内置）。构建脚本会过滤环境 PATH
    中来源不明的 ICU 副本，避免打包进不匹配版本。
