# MD5 哈希逆向分析器（crypto.md5_reverse）

面向 CTF 与密码学学习的**离线** MD5 候选分析工具。

> 重要：MD5 是单向哈希函数，无法被“解密”。本工具通过在用户指定的候选空间
> （单候选、本地字典、有限字符集暴力）中枚举并计算 MD5，寻找与目标一致的
> 候选值。“未找到”只代表当前搜索空间内未找到，不代表原文不存在。

## 功能

- 单候选验证 / 批量 Hash 验证（一个候选对多个 MD5）。
- 本地字典逐行匹配（严格 UTF-8，仅去除 CR/LF，保留候选内部空格）。
- 有限字符集暴力搜索（itertools.product 流式生成，不整体驻留内存）。
- 搜索空间预估、进度（字典按文件读取位置、暴力按理论进度）、速度统计、
  任务取消。
- MD5 格式校验（32 位十六进制、大小写不敏感、自动小写化）。
- 候选一律按 UTF-8 编码计算 MD5；空字符串候选受支持。

## 安全边界

- 完全离线：不联网、不上传 Hash、不调用任何在线查询或破解 API。
- 不做远程认证爆破、数据库破解、凭据窃取等能力。
- 暴力默认最大长度 5（上限 8），大搜索空间给出明确提示。

## 结构

`validators.py`（输入校验/搜索空间）→ `generators.py`（流式候选生成）→
`tool.py`（BaseTool，经 TaskManager 执行、可取消、统一 ToolResult）→
`infrastructure/crypto/md5_provider.py`（统一 MD5 计算）。

CTF 分类下的“MD5 Hash 分析”（`ctf.md5_reverse`）是同一实现的快捷入口，核心
逻辑只有一份。
